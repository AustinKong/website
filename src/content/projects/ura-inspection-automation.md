## Overview

As tech lead for my NUS capstone project with the Urban Redevelopment Authority, I led a five-person team building an inspection automation platform for more than 7,000 annual building reports.

## What I worked on

I designed a web, queue, and worker pipeline connecting React and Express with PostgreSQL, Azure Service Bus, Blob Storage, and containerized Python workers. The workflow combines computer vision with human validation before generating reports.
